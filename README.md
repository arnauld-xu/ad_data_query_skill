# ad-organic-traffic

Cursor 插件：用 Metabase 查自然流量、广告流量、内容主题、关联产品和赛道匹配。

别人安装时使用这个仓库地址：

https://github.com/arnauld-xu/ad_data_query_skill

在 Cursor 里打开 Customize，选择 From GitHub Repository，粘贴上面的地址，然后安装 `ad-organic-traffic`。

团队管理员也可以在 Dashboard → Plugins & MCPs → Add Marketplace → Import from Repo 里粘贴同一地址。

安装后需要各自登录一次 Metabase。
